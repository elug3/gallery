# gallery

Prada product image scraper (`prada/main.py`) plus Dupli1-shaped `info.json`.

```bash
python3 prada/main.py -o images <prada-product-url>
```

See [docs/prada-info-json.md](docs/prada-info-json.md) for the `info.json` schema and how it maps to [elug3/dupli1](https://github.com/elug3/dupli1) parent products + variants.
